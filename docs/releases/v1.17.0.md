## v1.17.0 — Configurable HTTP port and live config reload

### What changed

The HTTP server no longer hardcodes `127.0.0.1:21001`. Set the port (and
host) with `--port` / `--host`, the `SASSYMCP_PORT` / `SASSYMCP_HOST`
environment variables, or the new `http.port` / `http.host` keys in
`config.json` — whichever you set wins in that order.

Editing `config.json` while the server runs now takes effect without a
manual restart: ordinary settings apply on next read, and changing the port
restarts the listener automatically (graceful re-exec, or a supervised
respawn under `sassymcp supervise`). Disable with `http.liveReload: false`
or `SASSYMCP_NO_CONFIG_WATCH=1`.

Also fixed: the OAuth protected-resource metadata now advertises the real
bind URL instead of a hardcoded `http://localhost:21001`, which was failing
clients' exact-match address checks (seen with Claude Code over
`127.0.0.1`).

### Upgrade notes

No action required — defaults are unchanged (`127.0.0.1:21001`). If you
previously worked around the port being fixed (custom launchers, firewall
rules pointing at 21001), those keep working; the new knobs are purely
additive.
