## v1.4.1 — Marketplace readiness + CI deprecation cleanup

Two infrastructure fixes surfaced by the v1.4.0 CI run:

### What changed

- **`sassymcp-vscode/LICENSE`** — vsce flagged "LICENSE, LICENSE.md, or LICENSE.txt not found" when packaging the .vsix. The repo's MIT LICENSE was at the root only; vsce looks inside the extension dir. Bundling it in fixes the warning and unblocks VS Code Marketplace publish (which rejects extensions without an in-package license).
- **`.github/workflows/release.yml`** — Added `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24=true` at the workflow env level. Silences GitHub's Node.js 20 deprecation warnings and locks in forward-compat ahead of the June 2026 default switch + September 2026 node20 removal.

### Functional changes

None. The `sassymcp.exe`, `sassymcp.dxt`, and `sassymcp-1.4.1.vsix` artifacts produced from this tag are byte-equivalent to v1.4.0 except for the embedded version string and the LICENSE file inside the .vsix.

### Compatibility

- All v1.4.0 install paths continue to work. No config or behavioural changes.
- Marketplace publishers: `vars.PUBLISH_VSIX=true` + `secrets.VSCE_PAT` will now succeed against the v1.4.1 .vsix where v1.4.0's would have rejected on the missing-license check.
