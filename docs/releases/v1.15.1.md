## v1.15.1 — Release pipeline repair

### What changed

No functional change to the server. 1.15.0 reached PyPI but its GitHub Release
and MCP Registry listing stalled because `build-macos` requested retired
`macos-13`. `release` and `publish-registry` both `needs:` that job. This
patch moves Intel to `macos-15-intel`, Apple Silicon to `macos-15`, and sets
PyPI `skip-existing: true` so a partial publish can be retried.

### The bug / motivation

v1.14.3 and v1.14.4 GitHub Actions runs ended `cancelled` on the forever-queued
macos-13 job, which is why `/releases/latest` stayed on v1.14.2 even after
ubuntu jobs had published later versions to PyPI. 1.15.0 hit the same stall,
then could not retry PyPI without `skip-existing`.

### The fix / approach

`.github/workflows/release.yml`: macos-13 → macos-15-intel; macos-14 →
macos-15; `pypa/gh-action-pypi-publish` `skip-existing: true`. Version bump
only in `sassymcp/__init__.py`.

completing (run 26, 2026-09-14).
