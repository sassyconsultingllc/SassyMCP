## v1.14.1 — SelfMod removed entirely (no gate)

### What changed

Self-modification is gone — not opt-in, not stubbed as tools. There is no
`selfmod` tool group and no `sassy_selfmod_*` surface. Marketplace graders
require a fixed graded version; a gate was insufficient.

### Approach

- Dropped `selfmod` from `TOOL_GROUPS`
- Removed `is_selfmod_enabled` / `exclude_gated_modules`
- Replaced `sassymcp/modules/selfmod.py` with an importable no-op
- Scrubbed README / persona / setup / skills marketing of hot-reload SelfMod
- Protected-path refusals point at checkout/PR workflow

### Verification

```ps1
$env:PYTHONPATH='.'
python -m pytest tests/test_discovery.py tests/test_tool_loader_boost.py -q
python tools/verify_audit_fixes.py
```

### Compatibility

- Callers of `sassy_selfmod_*` will no longer see those tools
- `SASSYMCP_ENABLE_SELFMOD` is ignored (variable has no effect)
- Source-tree edits must be done outside the running MCP server
