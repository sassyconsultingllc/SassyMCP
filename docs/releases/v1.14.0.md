## v1.14.0 — Marketplace compliance: SelfMod gated, token banner hardened

### What changed

Public / packaged installs no longer expose SelfMod (rewrite / hot-reload)
tools. Marketplace graders require a fixed graded version; stubs that still
advertised self-edit were rejected. The startup banner no longer prints the
raw bearer token to stdout.

### Motivation

CuratedMCP review: *Not approved — SelfMod lets the installed binary
rewrite/hot-reload its own code after install; audits listed world-readable
tokens, token-on-stdout, admin MSI, non-reproducible build. Resubmit via
SHA256-pinned .mcpb.*

MSI path/scope hardening landed earlier; this release closes SelfMod +
banner for the resubmit.

### Approach

- `is_selfmod_enabled()` / `exclude_gated_modules()` in `_tool_loader.py`
- Frozen builds: `register()` returns without tools
- Source: require `SASSYMCP_ENABLE_SELFMOD=1`
- `_print_banner` uses `<token-from-sassymcp-show-token>` placeholder
- Directory listing copy: SHA256-pinned `.mcpb` or PyPI — no unverified
  exe curl

### Verification

```ps1
python -m pytest tests/test_discovery.py tests/test_tool_loader_boost.py -q
$env:SASSYMCP_ENABLE_SELFMOD='1'; python -c "from sassymcp.modules._tool_loader import is_selfmod_enabled; assert is_selfmod_enabled()"
```

### Compatibility

- Packaged / default users: SelfMod tools disappear from the tool list
  (intentional).
- Developers who relied on SelfMod: set `SASSYMCP_ENABLE_SELFMOD=1` when
  launching from source.
- Auth tokens: use `sassymcp show-token` instead of copying from the banner.
