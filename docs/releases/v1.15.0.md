## v1.15.0 — Batch fan-out, structured output, event-loop hygiene

### What changed

Tool results stop arriving double-encoded, blocking work stops running on the
event loop, and a single call can fan out across many tools. MINOR: the output
shape of 93 tools changed.

Added `sassy_batch` (concurrent multi-tool call under the normal audit /
validation / rate-limit path). 93 tools now emit real `structuredContent`
instead of a `{"result": "<json string>"}` envelope. `sassy_memory_recall` /
`sassy_memory_forget` return shapes changed. 70 event-loop blockers removed.
`sassy_combo_pr_review`, `sassy_update_apply`, and `sassy_setup_status` bugs
fixed. pytest collection no longer dies on `tests/test_intercept.py`.

### The bug / motivation

Annotated `-> str` tools that `json.dumps(...)` reached clients double-encoded.
`async def` bodies with no `await` blocked the loop. `test_intercept.py` is a
script named `test_*.py`, so `pytest tests` aborted during collection.

### The fix / approach

Return types moved to `dict[str, Any]` or TypedDict (10 with `outputSchema`).
64 fake-async tools converted to `def` so the audit wrapper offloads them;
genuine async helpers use `asyncio.to_thread`. Licence background tasks keep a
strong reference. ruff installed and triaged to zero (with BLE001/S110/S112
ignored by design).

### Test coverage

- Collection no longer INTERNALERRORs on `tests/test_intercept.py`.
- Existing discovery / loader / concurrency suites still apply.

### Verification

```ps1
python -m pytest tests/test_discovery.py tests/test_tool_loader_boost.py tests/test_concurrency_integration.py -q
```

Do not collect `tests/test_intercept.py` via pytest; it is a script (assertions
at import, `sys.exit`). Known issue unchanged: licence revocation checks are
scheduled before an event loop exists and do not run.

### Compatibility

**Breaking** for anything that parsed tool `result` as a JSON string. Read the
object from `structuredContent` / the result payload directly. 17 prose tools
(e.g. `sassy_write_file`) stay `-> str`.

### Files touched

See root `CHANGELOG.md` `[1.15.0]` — server modules, ruff config, intercept
test layout.
