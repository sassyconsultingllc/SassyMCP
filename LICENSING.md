## Is SassyMCP open source?

No. The source is public on GitHub so you can read and audit what it does on your machine, which matters for a tool that runs shell commands and controls devices. But the license is proprietary:

- **You can:** read the source, audit it, and modify it for your own personal use.
- **You can't:** redistribute it, sell it, publish modified versions, host it as a service for others, or build a competing product from the source.
